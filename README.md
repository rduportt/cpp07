# CPP Module 07

> C++ templates.

## What's inside

- Function templates: swap, min, max
- iter on arrays
- Class template Array

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
